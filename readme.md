# 🌤️ Skybound: Landing Page

A responsive-ready landing page built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. The goal was to recreate a given design using only HTML and CSS.

**🔗 Live demo:** https://luchenko04.github.io/odin-landing-page/

## ✨ Features

- Semantic HTML structure: `header`, `nav`, `main`, `section`, `footer`
- Layout built with **Flexbox** (rows, columns, wrapping, alignment)
- Design tokens via **CSS variables** (`:root`)
- Consistent spacing with the **box model** and `box-sizing: border-box`
- Smooth hover transitions on links and buttons
- Roboto font loaded from Google Fonts

## 🧱 Page Sections

1. **Header:** logo and navigation links
2. **Hero:** headline, subtext, call-to-action button and image placeholder
3. **Info:** four feature cards with illustrations
4. **Quote:** full-width highlighted quote with author
5. **Call to action:** sign-up block
6. **Footer:** copyright

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, custom properties)
- Git & GitHub Pages

## 📚 What I Practiced

- Breaking a design into sections and nested flex containers
- Centering content with `max-width` and `margin: 0 auto`
- `flex`, `gap`, `justify-content`, `align-items`, `flex-wrap`
- Writing small, atomic commits with clear messages

## 🚀 Run Locally

```bash
git clone git@github.com:luchenko04/odin-landing-page.git
cd odin-landing-page
```

Then open `index.html` in your browser.
